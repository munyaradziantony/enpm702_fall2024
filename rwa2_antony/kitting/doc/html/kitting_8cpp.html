Performs a specified task (pick_block or place_block) on the blocks using the gripper.

This function simulates either picking a block from a bin or placing a block into a tray based on the specified task. It validates the prerequisites for each action and updates the counts accordingly. For a pick_block task, it ensures the bin has blocks and the gripper is empty before picking. For a place_block task, it verifies that the gripper is holding a block before placing it into the tray.

Parameters
[in]taskThe task to be performed, either "pick_block" or "place_block".
[out]bin_countReference to the current count of blocks in the bin. Decreases when a block is picked.
[out]tray_countReference to the current count of blocks in the tray. Increases when a block is placed.
[out]gripper_statusReference to the status of the gripper. Set to true when holding a block, false when empty.
